# Roadmap

The roadmap outlines the long-term direction of Project Mosaic.

Items may move between phases as development progresses.

The roadmap represents product goals rather than a strict development schedule.

---

# Phase 1 — Foundation

Status: In Progress

Goal:

Establish the core architecture and user experience.

Objectives:

- Core dashboard layout
- Three-zone architecture
- Event scheduler
- Card framework
- Animation system
- Basic configuration
- Initial documentation
- GitHub repository

Success Criteria:

A stable dashboard capable of displaying modular cards using the scheduler architecture.

---

# Phase 2 — Core Information

Goal:

Transform Mosaic into a useful everyday companion.

Features:

- Calendar
- Weather
- Sports
- Music
- Reddit
- RSS
- Holidays
- Today in History

Success Criteria:

Mosaic becomes useful enough to leave running every day.

---

# Phase 3 — Smart Home

Goal:

Integrate the home into Mosaic.

Features:

- Home Assistant
- Presence detection
- Lighting status
- Door sensors
- Garage status
- Camera events
- Timers
- Smart device monitoring

Success Criteria:

Mosaic becomes aware of the home environment.

---

# Phase 4 — Companion Experience

Goal:

Create a complete management platform.

Features:

- Companion website
- Live dashboard preview
- Widget management
- Scheduler editor
- Theme editor
- Sports configuration
- Discovery configuration
- User profiles

Success Criteria:

Nearly every aspect of Mosaic can be configured without editing code.

---

# Phase 5 — Intelligence

Goal:

Allow Mosaic to adapt naturally throughout the day.

Potential Features:

- Context-aware scheduling
- Routine detection
- Presence awareness
- Adaptive priorities
- AI-assisted summaries
- Personalized recommendations

Success Criteria:

The dashboard naturally changes emphasis based on the user's day.

---

# Phase 6 — Ecosystem

Goal:

Expand beyond a single display.

Potential Features:

- Multiple displays
- Mobile companion
- Desktop companion
- Companion control device
- Voice integration
- Plugin architecture
- Public API

Success Criteria:

Mosaic becomes an extensible platform rather than a single application.

---

# Future Ideas

Ideas that may be explored:

- AI-generated daily briefing
- Family mode
- Guest mode
- Vacation mode
- Travel dashboard
- Digital photo integration
- Fitness summaries
- Reading tracker
- Finance overview
- Gardening dashboard

These ideas remain exploratory and should not influence the current architecture until formally accepted.

---

# Guiding Principle

Features are added when they improve the experience—not simply because they are possible.

Project quality always takes precedence over feature count.
